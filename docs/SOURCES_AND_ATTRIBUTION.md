## Adaptation notes

**Quant Strategy Framework.** The reference builds a universe by filtering on liquidity, volatility and quality, de-duplicating by correlation, and exporting the list. It reads *current* market cap and average volume from a live vendor, which is look-ahead and survivorship bias in a historical test. `backtesting/universe.py` keeps the filter, de-duplicate and freeze flow but computes every criterion from bars dated strictly before `as_of`, records the reason for each exclusion, fingerprints the result (SHA-256), and reports frozen members whose data ends early. Not used: the vendor-metadata fetch, the sector tables, the single-position backtest engine (FinSight already has event-driven and portfolio engines). The Bollinger z-score mean-reversion baseline uses trailing closes only and is filled by the existing next-bar engine. `backend/tests/fixtures/baseline_regression.json` follows the reference's practice of committing frozen results; it was generated from seeded synthetic data by this project's own engine, not taken from the reference.

**RL Portfolio Management.** Kept: a flat observation, a softmax action over assets plus cash, swappable reward schemes, a transaction-cost model, and the idea of comparing a policy with simple allocation baselines. Changed on purpose: (1) execution is at the next bar's open and the position earns the open(t+1) to open(t+2) return, while the reference earns the close-to-close return from the decision bar; (2) every action passes through the deterministic `risk/allocation.py` limits; (3) the plan's cost, turnover and drawdown reward is one of the schemes; (4) evaluation is strictly chronological over repeated seeds against equal-weight and buy-and-hold baselines run through the same environment, and it reports how many seeds beat each baseline.

**Financial Research Agent.** Kept: specialist analysts (fundamentals, risk, sentiment) feeding a coordinator. Changed on purpose: analysts are deterministic and see only retrieved evidence; every statement is a verbatim evidence sentence with its own citation ID, so the existing citation-linkage check, claim-support screen, checkpointing and mandatory human review apply to the memo unchanged. In the reference each analyst prompts an LLM with retrieved context text; FinSight's analysts make no LLM call. The technical analyst is descriptive only, the hypothesis proposal states a question to test and no expected return, and the methodology critic rejects leaky features, missing benchmarks, in-sample evaluation, missing evidence and performance claims.

**Banking Fraud and Credit Risk ML.** Compared with the existing code and nothing was added. FinSight's `feedback/drift.py` already implements PSI and the KS statistic (the reference has PSI only), the project already has MLflow tracking hooks and experiment lineage, three CI workflows (the reference has one test job), and Docker. Fraud and credit scoring are out of product scope.

**Stock Agent System.** No licence file exists in the archive, so the project rules (`references/REPOSITORY_CATALOG.md`) treat it as architecture-only. What was studied is the separation of analysis agents from trading logic and the LLM-judge evaluation idea; both were already in the FinSight design. Nothing was copied or closely paraphrased.
